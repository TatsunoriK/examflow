# เปิด ExamFlow บนเครื่อง

ต้องใช้ Node.js 24 ขึ้นไป เปิด terminal จากโฟลเดอร์โครงการแล้วทำตามนี้:

```sh
cd portable
npm install
npm run build
npm start
```

เปิด http://127.0.0.1:4173/ แล้วลองสลับหน้าระหว่างอาจารย์และนักเรียนได้

เวอร์ชันนี้ใช้บัญชีทดลองร่วมกันหนึ่งบัญชี เพื่อทดสอบหน้าตาและการทำงานบนเครื่องเท่านั้น ไม่ใช่ระบบบัญชีสำหรับใช้งานจริง เซิร์ฟเวอร์รับการเชื่อมต่อที่ 127.0.0.1 เท่านั้น

ข้อสอบ ผลสอบ และวิดีโอเก็บใน `portable/data/` บนเครื่อง ข้อมูลนี้ไม่ถูกนำขึ้น GitHub ไฟล์ที่สร้างจากการ build และส่วนประกอบที่ติดตั้งก็ถูกละเว้นเช่นกัน

การเริ่มสอบยังต้องกดยินยอมแชร์ทั้งหน้าจอในเบราว์เซอร์ด้วยตนเอง ใช้ Chrome หรือ Edge บนคอมพิวเตอร์ หากเบราว์เซอร์ฝังในแอปไม่รองรับการแชร์หน้าจอ ให้เปิด URL ใน Chrome หรือ Edge โดยตรง

ซอร์สสำหรับ Sites ยังคงอยู่ในโฟลเดอร์ `app/` เวอร์ชันนี้ไม่ได้เผยแพร่เว็บออนไลน์
